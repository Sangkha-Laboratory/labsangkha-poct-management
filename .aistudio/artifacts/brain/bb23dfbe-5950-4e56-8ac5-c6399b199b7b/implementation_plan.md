# แผนงานปรับปรุงระบบคลังวัสดุแผ่นตรวจ & น้ำยาควบคุม (Lab Internal Stock)

## 1. วัตถุประสงค์และปัญหาที่ต้องแก้ไข (Objectives & Core Issues)
1. **หน้าจอใช้งานยากและรก**: ข้อมูลปะปนกันระหว่างฟอร์มรับเข้า รายการพัสดุ แบตเตอรี่ และบาร์โค้ด ขาดการแยกสัดส่วนที่ชัดเจน
2. **ยังไม่เชื่อมต่อฐานข้อมูลจริง**: ปัจจุบันมีการ fallback ไปใช้ `localStorage` ทำให้ข้อมูลไม่ซิงก์ข้ามเครื่องหรือหายเมื่อล้างเบราว์เซอร์
3. **เครื่องสแกนบาร์โค้ด ยิงไม่ติด**: ฟังก์ชันสร้างบาร์โค้ดเดิมในหน้านี้ใช้สูตรวาดเส้น SVG จำลองแบบสุ่ม ไม่ตรงตามโครงสร้างมาตรฐานสากล (Code 128) ทำให้หัวอ่านสแกนเนอร์ในห้องแล็บปฏิเสธการอ่าน
4. **พิมพ์ไม่ออก/ล้นในเครื่อง Zebra (50x20 mm)**: ขนาดเดิมตั้งไว้ที่ 50x25 mm และไม่มี CSS Page Definition ที่แม่นยำ ทำให้กระดาษม้วนของ Zebra เลื่อนทับหน้า หรือเซนเซอร์ช่องว่าง (Gap Sensor) อ่านผิดพลาด

---

## 2. รายละเอียดสถาปัตยกรรมและการปรับปรุง (Architecture & Implementation Plan)

### ส่วนที่ 1: การเชื่อมต่อฐานข้อมูล Supabase 100% (ตัด localStorage ทั้งหมด)
- **สถาปัตยกรรม Schema**:
  - ตารางกายภาพ: `dtx_system.strip_reagent_items`
  - วิวสาธารณะ: `public.dtx_strip_reagent_items` (มี prefix `dtx_` ตามกฎข้อบังคับของโปรเจกต์)
- **การปรับปรุง Service (`src/lib/supabase.ts` & `src/components/StripReagentStock.tsx`)**:
  - ลบโค้ด `localStorage.getItem('dtx_strip_items')` และ `localStorage.setItem('dtx_strip_items', ...)` ออกทั้งหมด
  - ปรับการอ่านและบันทึกข้อมูลทุกขั้นตอน (รับเข้า, เปิดขวดใช้งาน, อัปเดตสถานะ, ตัดสต็อก, ลบ) ให้วิ่งผ่าน Supabase API หรือ Backend Proxy `/api/strip-reagent-items`
  - หากไม่มีข้อมูลในฐานข้อมูล ให้แสดงเป็นอาร์เรย์ว่าง `[]` อย่างถูกต้องตามกฎ No Mock Data

---

### ส่วนที่ 2: แก้ไขระบบสร้างบาร์โค้ดให้สแกนได้ 100% (Compliant Code 128)
- แทนที่ฟังก์ชันวาดเส้น SVG แบบสุ่มเดิม ด้วย **JsBarcode (Code 128 Subset B/C)** ที่ได้มาตรฐานสากล
- คำนวณ Quiet Zone (ระยะเว้นขอบซ้าย-ขวา) และขนาดความกว้างของแท่งบาร์โค้ด (Narrow Bar Width) ให้เหมาะสมกับการอ่านด้วยเครื่องสแกนเลเซอร์/CCD หัวอ่านของแล็บ
- เพิ่มกล่อง **"สแกนบาร์โค้ดค้นหา/เปิดใช้งานทันที" (Quick Barcode Scanner Box)** รองรับการยิงปืนบาร์โค้ดเพื่อค้นหากล่อง หรือสั่งเปิดขวดได้ในคลิกเดียว

---

### ส่วนที่ 3: ปรับปรุงระบบพิมพ์สติกเกอร์สำหรับเครื่องพิมพ์ Zebra ขนาด 50x20 mm
- **ขนาดสติกเกอร์มาตรฐาน 50x20 มม.** (ตามที่แล็บใช้งานจริง):
  - ปรับขนาด CSS `@page { size: 50mm 20mm; margin: 0; }` ให้พอดีกับกระดาษม้วนความร้อน Zebra โดยไม่มีส่วนเกินตกขอบ
  - จัด Layout สติกเกอร์ 3 บรรทัดกระทัดรัด:
    - บรรทัดที่ 1: หัวหน่วยงาน (`รพ.สังขะ • งานชันสูตร`) + ประเภทวัสดุ
    - บรรทัดที่ 2: บาร์โค้ด Code 128 + รหัสกล่อง/ขวด (เช่น `ST-LOT2026A-01`)
    - บรรทัดที่ 3: `LOT: 2026-A` | `EXP: 2026-12-31` | `เปิด: ___/___/___`
- **ระบบคำสั่ง Zebra ZPL (Zebra Programming Language)**:
  - เพิ่มตัวเลือก **"ส่งออก ZPL" (Zebra ZPL Output)** สามารถกดคัดลอกคำสั่ง ZPL หรือดาวน์โหลดไฟล์ `.zpl` เพื่อส่งตรงไปยัง Zebra Setup Utilities หรือ Network Zebra Printer ได้โดยตรง 100% ไม่เพี้ยนจากไดรเวอร์เบราว์เซอร์

---

### ส่วนที่ 4: การ Redesign หน้าจอให้คลีน ใช้งานง่าย เป็นมืออาชีพ (UI/UX Overhaul)
ปรับโครงสร้างหน้าจอใหม่เป็นรูปแบบ **Clean Dashboard & Medical Lab Portal**:
1. **แถบสรุปสถานะบนสุด (Inventory Summary KPI Cards)**:
   - 📦 แผ่นตรวจพร้อมใช้ (จำนวนกล่อง / จำนวน Tests รวม)
   - 🧪 น้ำยาควบคุมพร้อมใช้ (Control Solution Level 1, 2, 3)
   - ⚡ กำลังเปิดใช้งานในแล็บ (In-use ขวดที่เปิดแล้ว พร้อมแสดงวันนับถอยหลังหมดอายุ)
   - ⚠️ ใกล้หมดอายุ (< 30 วัน) หรือใกล้หมดสต็อก
2. **การจัดแท็บการทำงานหลัก 4 แท็บชัดเจน**:
   - **แท็บ 1: สต็อกคงเหลือ (Current Stock & In-Use)**
     - ตารางคลีน โมเดิร์น แยกสถานะด้วย Badge สีชัดเจน (พร้อมใช้, กำลังเปิดใช้งาน, ใช้หมดแล้ว)
     - ปุ่ม Action รวดเร็ว: [เปิดขวดใช้งาน], [ตัดยอดหมด/ทิ้ง], [พิมพ์สติกเกอร์]
   - **แท็บ 2: รับเข้าพัสดุใหม่ (Receive Stock)**
     - ฟอร์มรับเข้าที่สะอาดตา กรอกเลข LOT, วันหมดอายุ, จำนวนกล่อง ระบบ Gen รหัส Unique Item Code และบาร์โค้ดให้อัตโนมัติ
   - **แท็บ 3: ประวัติรับเข้าและเบิกใช้ (Stock Movement History)**
     - บันทึกการเคลื่อนไหว วันที่รับเข้า วันที่เปิดใช้งาน ผู้เปิดใช้งาน และวันที่จำหน่ายออก
   - **แท็บ 4: ศูนย์พิมพ์สติกเกอร์บาร์โค้ด Zebra (50x20 mm Center)**
     - เลือกพิมพ์รายกล่อง หรือพิมพ์ยก LOT
     - พรีวิวสติกเกอร์ขนาด 50x20 mm จริง
     - ปุ่มสั่งพิมพ์ผ่านเบราว์เซอร์ และปุ่มคัดลอก ZPL Code
   - *(ส่วนของถ่านเครื่องตรวจ จะถูกจัดเป็นเมนูย่อยหรือแท็บแยกเพื่อไม่ให้ปะปนกับน้ำยาแล็บ)*

## 3. ขั้นตอนการดำเนินงาน (Execution Steps)
1. ปรับแก้ `src/lib/supabase.ts` เพื่อเชื่อมต่อ table `strip_reagent_items` อย่างสมบูรณ์และตัด `localStorage` ออก
2. ปรับปรุง `src/components/StripReagentStock.tsx` และ `BarcodePrinterModal.tsx`:
   - ปรับปรุงการสร้างบาร์โค้ดด้วย JsBarcode แท้
   - ปรับ Label Template เป็น 50x20 mm พร้อมฟังก์ชัน ZPL Code
   - Redesign โครงสร้าง UI ทั้งหมดให้สะอาด แยกแท็บชัดเจนตามแผน
3. ทดสอบ Lint และ Compile ให้ผ่าน 100% ปราศจาก Error
